## 1. 시나리오 제목
아르바이트 일당 계산기




## 2. 시나리오 (5~10줄)
이 프로그램은 아르바이트생이 하루 근무를 마치고 자신의 일당을 간편하게 확인하기 위해 기획되었습니다. 사용자는 자신의 영문 이니셜, 시급, 근무 시간을 입력합니다. 프로그램은 입력된 시급과 시간을 곱하여 오늘 받을 총급여를 계산하고, 여기에 식비 등 추가로 받은 지원금을 더해 최종 일당을 출력합니다. 1차 단계에서는 단순 계산에 집중하며, 향후 주휴수당 판별(2차), 메뉴 시스템, 월간 기록 관리로 확장할 예정입니다.

## 3. 예상 기능 및 메뉴 (최소 5개)

1.근무자 이니셜 입력 

2.시간당 급여(시급) 설정 

3.실제 근무 시간 입력 

4.식비 지원금 입력 

5.최종 합산 일당 출력 및 종료

해결: 최종 결과값인 totalPay를 정수형으로 선언하고, 계산 과정에서 실수를 더한 뒤 정수로 저장하여 소수점 이하를 자연스럽게 처리하는 방식을 적용함.

## 🟩 [2차 과제: V2.0] 조건 분기 적용 (조건문) - 향후 작성 예정
### **✨2차 과제 업데이트 내용:**
  * 내용.
추가된 기능:


1. 주휴수당 대상 판별: 주당 근무 시간에 따른 주휴수당 지급 여부 확인 (if문 활용)


2. 근무 등급별 보너스 지급: 성실도나 업무 강도에 따른 보너스 비율 선택 (switch문 활용)


3. 중첩 조건문: 주휴수당 대상자 중에서도 특정 조건(예: 근무 시간 20시간 초과)을 만족할 시 추가 인센티브 판별
    
### **🤖 AI 파트너십 과정**

 1. 내용 1.
 
 프롬프트 요약: "아르바이트 일당 계산기에서 '주휴수당 지급 여부'를 판별하기 위한 다중 조건문(if-else if-else) 설계와 조건 설정 논의"   
 
 적용 내용: 주당 근무 시간이 15시간 미만, 15시간 이상 40시간 미만, 40시간 초과인 경우로 나누어 주휴수당 지급 대상 여부를 판별하는 로직을 설계함   
 
2. 내용 2

프롬프트 요약: "사용자의 업무 강도나 성실도에 따라 보너스를 다르게 지급하기 위해 switch~case 문과 중첩 if문을 활용하는 방법 논의"   

적용 내용: switch문을 통해 보너스 옵션(1.일반, 2.바쁨, 3.매우 바쁨)을 선택하게 하고, 그 내부에서 if문을 한 번 더 사용하여 특정 근무 시간을 넘긴 경우 인센티브를 추가하는 중첩 구조를 적용함   


### **🛠️ Troubleshooting & 기술 회고:**

문제 1: 프로그램 실행 결과, '최종 합산 일당' 부분에 변수 값이 출력되지 않고 %d원이라는 텍스트가 문자 그대로 출력됨.

원인: printf 함수 내에서 서식 지정자를 사용할 때 % 기호를 중복 사용(%%d)했거나, 따옴표 뒤에 출력할 변수명(totalPay)을 누락하여 발생한 서식 오류임.

해결: AI 파트너와의 협업을 통해 printf("3. 최종 합산 일당: %d원\n", totalPay);와 같이 형식 지정자와 출력 변수를 정확히 매칭하여 수정함으로써 정상적인 숫자 값이 출력되도록 조치함.

문제 2: 수당 판별 로직과 보너스 계산 코드가 포함되어 있음에도 불구하고, 최종 결과값에는 1차 과제와 동일하게 보너스가 합산되지 않은 금액이 출력됨.   

원인: 보너스가 포함된 finalPay를 계산해 두었으나, 코드 마지막 단계에서 보너스가 누락된 1차 과제용 산술식(totalPay)이 다시 실행되면서 결과값이 덮어씌워지는 논리적 오류가 발생함.   

해결: 중복된 연산 식을 정리하고, if문과 switch문을 통해 최종 결정된 bonusAmount가 모두 합산된 finalPay를 최종 출력 변수로 사용하도록 구조를 변경하여 해결함.

### **🛠️ Troubleshooting & 기술 회고:**
  문제 1: 세미콜론 누락으로 인한 컴파일 에러

상황: printf("\n------------메인메뉴------------\n") 줄 끝에 세미콜론이 빠져서 컴파일이 안 됨.
해결: AI가 정확한 줄 번호와 함께 알려줘서 두 곳 모두 ; 추가하여 해결.

문제 2: 변수명 대소문자 / 오타 문제

상황: calculateBonus 함수 안에서 bonusAmount = (wage * Hours) * 0.05; 라고 잘못 입력. C언어는 대소문자를 구분하기 때문에 Hours가 존재하지 않는 변수로 인식됨.
해결: 매개변수명은 소문자 hours로, 변수명은 함수 내에 선언된 bonus로 통일. C는 대소문자에 매우 민감하다는 점을 배움.
